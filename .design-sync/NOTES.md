# design-sync notes — c12z.io

- **Shape is nominally `package`, but the converter is not used.** This repo is an Astro site,
  not a component package: no `exports`/`main`, no `dist/`, no Storybook. 110 `.astro` components
  cannot be bundled into the React runtime that renders Claude Design output, and the 4 `.tsx`
  files (`BottomBar`, `toc`, `progressCircle`, `SortToggle`, plus `old.TableOfContent`) aren't
  worth a bundle entry on their own. Scope agreed with the user: **tokens + styles only**.
  There is no `_ds_bundle.js` and no `_vendor/`.

- **The bundle is generated by hand**, not by `package-build.mjs`. `src/styles/global.css` is
  sliced by line range into `tokens/{colors,typography,layout,texture}.css` + `base/reset.css`;
  `lettering.css` → `base/prose.css`, `typo.css` → `base/elements.css`. Generator script for the
  four foundation preview cards lives only in the session scratchpad — if the token set changes
  materially, regenerate the cards by hand or re-run a fresh sync.

- **No `_ds_sync.json`.** Off-script layout with no converter anchor, so there are no render
  hashes to record. Consequence: every re-sync re-verifies and re-uploads everything. That is
  cheap here (25 files) and is the honest state.

- **Two deliberate deviations from the site's own CSS:**
  1. Page-shell geometry (`body` centred at `--screen-n`, `padding`, flex column, `main {}`) was
     moved out of `base/reset.css` into `base/page-shell.css`, which `styles.css` does **not**
     import. Left in, it would have pinned every design the agent produces to an 896px centred
     column. `min-height: 100dvh` stayed in `reset.css` so the background still fills the viewport.
  2. `.woff` fallbacks dropped (woff2 only); font `src` paths rewritten to `./`; the paper-texture
     SVGs from `public/textures/` inlined as data URIs so the bundle is self-contained.

- **Verification was visual, in Chrome**, against a local `python3 -m http.server` in `ds-bundle/`.
  All four foundation cards checked: Tamago/Rubik/Cascadia all load, both themes switch, grain and
  fleck textures render, prose specimen matches the site.

- `ds-bundle/` is build output — regenerated each sync, not meant to be committed.
